核心功能

全栈 IM 能力，开箱即用

从消息收发到语音通话，从好友管理到管理后台，WorkChat 覆盖企业即时通讯的每一个环节。

💬

实时消息收发

支持单聊与群聊，文本、图片、文件、语音、视频六种消息类型，WebSocket 长连接毫秒级触达。

WebRTCP2P通话记录

好友管理群权限群公告

通知中心

回复、@提及、系统通知、好友请求、群邀请五大分类，桌面通知与提示音可配置，任务栏未读角标提醒。

分类通知角标提醒提示音

技术架构

网关独立，领域拆分

采用「网关独立 + 业务按领域拆分」的四层架构，支持从模块化单体平滑演进到微服务。

四层分层设计

长连接网关独立部署，专注连接管理与消息路由；业务服务按领域拆分，接口边界清晰后按需拆微服务。双通道分工：高频实时走 WebSocket，低频重逻辑走 HTTP REST。

  • ✓
    消息可靠性
    客户端 msgId 幂等去重 + 会话级 seq 有序 + ACK 送达回执 + 离线补发，保证消息不丢、不重、有序
  • ✓
    消息分表
    按 conv_id % 4 路由到 4 张分表，同会话恒落同表保证 seq 连续有序，后续平滑扩容到 8/16 表
  • ✓
    跨节点路由
    Redis Pub/Sub 订阅节点频道，uid→节点映射精准投递，单机起步无缝扩展到多节点
  • ✓
    乐观更新 + 超时去重
    发送方乐观渲染，服务端回显替换，30秒超时去重防重复，敏感词过滤后内容替换无感知

安全设计

多层安全防护，数据可靠可控

从传输层到业务层，从客户端到管理端，全方位守护通信安全。

🛡

安全是 IM 的生命线

端到端传输加密 · 敏感词过滤 · 滑动验证码防爆破 · 审计日志可追溯，每一层都经过精心设计。

🔑

JWT 双令牌认证

短期 access token + 可撤销 refresh token，Electron safeStorage 加密存储，过期自动刷新，多端连接管理。

🧩

滑动验证码防爆破

登录失败自动触发滑动验证码，防止暴力破解与机器人批量注册。

📝

敏感词过滤

服务端实时敏感词检测与替换，消息内容安全可控，管理端可配置敏感词库。

📤

文件上传校验

文件类型与大小限制，预签名 URL 时效控制，OSS 直传减轻网关压力。

📋

管理端审计日志

管理端操作全程审计，角色鉴权控制权限边界，首次登录强制改密。

🔒

contextIsolation 安全沙箱

Electron contextIsolation 保持开启，preload.js 桥接白名单 IPC，防止渲染层越权。
